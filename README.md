# 阿姨考勤 H5

家庭内部使用的家政阿姨考勤记账网页。**只有家人能进入（访问口令白名单），阿姨无需任何操作**——由家人按天记录「上班 / 缺勤」与应付工资，在日历、台账、统计页查看，支持按月统计与导出 Excel。

纯前端 + 一个极简 Node 服务，无需数据库、无需微信认证、无需小程序。

## 功能一览
1. **白名单登录**：统一访问口令，只有知道口令的家人能进入。
2. **考勤录入**：选日期 → 选「上班 / 缺勤」→ 填应付工资（上班默认 ¥200/天，缺勤默认 ¥0，均可手动改），简洁明了。
3. **日历可视化**：月历上按状态着色（上班绿 / 缺勤红 / 空缺素雅），点开看当日明细，可编辑/删除。
4. **全量台账**：所有成员可新增、编辑、删除，查看全部历史记录。
5. **月度统计**：按月筛选，自动汇总**出勤天数**、**缺勤天数**、**应付总额**，并用占比条呈现；可一键跳到当月日历。
6. **导出 Excel**：台账页/统计页一键导出当月 `.xlsx`（中文表头）。
7. **移动端适配**：针对手机微信浏览器优化，界面简洁。

## 技术栈
- 前端：Vue 3 + Vite + Vant 4（移动端 UI）
- 后端：Node.js + Express（极简 API）
- 存储：单 JSON 文件（`data/records.json`），零原生依赖
- 导出：SheetJS（前端生成 Excel）
- 鉴权：Node 内置 `crypto` 的 HMAC 令牌

## 本地运行
环境要求：Node.js 18+。

```bash
# 1. 安装依赖
npm install

# 2. （可选）修改访问口令
#    默认口令为 888888，可直接用；想改就在启动时用环境变量覆盖：
#    ACCESS_CODE=你的口令 npm run dev
#    或部署到服务器后用环境变量设置。多个口令用逗号分隔：ACCESS_CODE=888888,mama,baba

# 3. 启动（前后端一起跑）
npm run dev
```
- 前端：浏览器打开 http://localhost:5173
- 后端 API：http://localhost:3000
- 手机同一 WiFi 下访问：http://<你电脑的局域网IP>:5173

> 开发模式下前端（5173）与后端（3000）分端口，Vite 已配置代理把 `/api` 转发到后端，无需手动处理跨域。

## 生产/部署

> **为什么要用“稳定主机”？** 开发时看到的 `webview.*.sandbox…` 预览地址只是临时入口：工作空间会休眠，外部浏览器打开会提示「工作空间当前未在运行」，微信里能开也只是“当时还醒着”的时机问题。要让家人**随时、在任意浏览器（含微信「在浏览器中打开」）**都能稳定打开，并真正用上「添加到主屏幕」，需要把它部署到一个一直运行的地方。下面两种方式任选其一。

### 本地先自测
```bash
npm install
npm run build      # 构建前端到 dist/
npm start          # 生产模式：同一 Node 进程托管前端 + API（默认 3000）
```
浏览器打开 http://localhost:3000 即可，前后端同端口、无跨域。

### 方式 A：PaaS（Railway / Render / Fly.io，推荐不想管服务器）
1. 把本项目推到你的 GitHub 仓库（仓库需含 `package.json`、源码与新增的 `Dockerfile`）。
2. 在平台新建项目 → 连接该仓库；构建命令 `npm install && npm run build`，启动命令 `npm start`。
3. 在平台环境变量里设置：
   - `ACCESS_CODE` = 你的自定义口令（**务必改掉默认 888888**，多个用逗号分隔）
   - `JWT_SECRET` = 一段随机字符串
   - `PORT` = 平台分配的端口（一般平台自动注入，无需手填）
4. 部署完成后平台会给一个 `https://xxx.railway.app` 之类的域名，把这个域名发给家人即可。

### 方式 B：自有 VPS / NAS / 家里常开设备（Docker，推荐）
```bash
# 1) 准备环境变量（口令/密钥写在 .env，已被 git 忽略，不会泄露）
cp .env.example .env
#   然后编辑 .env：把 ACCESS_CODE / JWT_SECRET 改成你自己的值

# 2) 构建并后台启动（数据挂卷持久化到 ./data）
docker compose up -d --build
```
- 访问 `http://<服务器IP>:3000`（或套一层 nginx 反代 + HTTPS，见 `deploy/nginx.conf` 样例）。
- **数据持久化**：台账写在容器内的 `/app/data`，已通过 `docker-compose.yml` 挂到宿主 `./data`，重装/升级容器数据不丢。
- 不用 Docker 的话：`npm install && npm run build && npm start`，但需自己用 `systemd`/`pm2` 守护，并把 `data/` 放在持久目录（可用 `DATA_FILE` 指向，参见 `deploy/ayi-kaoqin.service` 样例）。

### 环境变量
| 变量 | 说明 | 默认 |
|---|---|---|
| `ACCESS_CODE` | 访问口令白名单，逗号分隔多个 | `888888`（部署前务必改） |
| `PORT` | 服务端口 | `3000` |
| `JWT_SECRET` | 令牌签名密钥（建议部署时设置） | 内置默认值 |
| `DATA_FILE` | 数据文件位置 | `data/records.json`（Docker 内为 `/app/data/records.json`） |

### 安全提示
- 这是**家庭内部**工具，建议部署在可信网络，或套一层反向代理 + HTTPS，必要时再加 Basic Auth。
- 部署前**改掉默认口令**；`JWT_SECRET` 设成随机串；数据文件 `data/records.json` 含全部考勤与工资，注意备份与权限。
- **部署路径**：PWA 的 `start_url`/`scope` 为 `/`，请部署在**域名根路径**。若必须放到子路径（如 `https://域名/ayi/`），需同步改 `vite.config.js` 的 `base` 与 `public/manifest.webmanifest` 的 `start_url`/`scope`。

## 使用说明（给家人）
1. 打开网页，输入家庭口令进入。
2. 点底部中间 **＋** 新增考勤：选日期 → 选「上班 / 缺勤」→ 填应付工资（上班默认 ¥200/天，缺勤默认 ¥0，均可改），保存即可。
3. **日历**：上班日期标绿色「上班」、缺勤标红色「缺勤」、空缺保持素雅；点开看当天明细、可编辑/删除。
4. **台账**：按月翻看全部记录（状态胶囊 + 应付工资），可编辑/删除，右上角「导出」生成 Excel。
5. **统计**：选月份看出勤天数、缺勤天数、应付总额及占比条；点「查看当月日历」可跳到日历页直观看哪天上班/缺勤；可导出 Excel。

## 像小程序一样用（添加到主屏幕 + 二维码）
本工具已做成 **PWA**，可以像小程序一样放在手机桌面上，老人不用在聊天记录里翻链接：

- **添加到主屏幕**：在手机**自带浏览器**（Safari / Chrome）打开本地址 → 点「分享 / 菜单」→「添加到主屏幕」，桌面会出现「阿姨考勤」App 图标，点开全屏、无浏览器地址栏。
- **二维码**：登录页底部或首页右上角「二维码」图标，可生成**当前部署地址**的二维码；发给家人扫码直达，或扫码后在浏览器打开并添加到主屏幕。
- 配了 Service Worker，离线也能打开页面（数据需联网同步）。

> ⚠️ **微信内打开不能直接“添加到主屏幕”**：第一次需微信右上角「…」→「在浏览器打开」，加一次桌面图标后，以后直接点桌面图标即可，不用再回微信找。
> PWA 必须 **HTTPS**；本服务与常见云主机均满足。二维码内容取当前域名，部署到任何地址都会自动对应。

## 常见问题
- **微信里打开白屏？** 微信内置浏览器一般可直接访问部署地址；若被拦截，点右上角「…」→「在浏览器中打开」即可。
- **数据存在哪？** 全部在 `data/records.json`，删除该文件即清空所有记录（请谨慎）。
- **忘记口令？** 改 `ACCESS_CODE` 环境变量重启服务即可。
